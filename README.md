# Hi, I'm Sneha

I'm a Computer Science and Engineering student at the University of South Florida, originally from Nepal.

I honestly love learning about how systems work from the inside. I like to take things apart, follow the logic step by step, and then build something better. That curiosity pulled me toward backend development, security engineering, and AI.

Right now, I’m working in cybersecurity while also building more projects in software engineering and AI. I’m still learning a lot, but I like staying curious and actually building things instead of only reading about them.

---

## What I’m working on

I’m mostly focused on:

* backend development with Python, FastAPI, APIs, and databases
* cybersecurity work like SOC workflows, alert investigation, and threat analysis
* AI tools that are actually useful for students, analysts, or developers
* full stack projects with React, Next.js, TypeScript, and modern web tools
* getting stronger at data structures, algorithms, systems, and software design

I like projects that come from real problems. If something feels repetitive, slow, or annoying to do manually, I usually start thinking about how to automate it or make the workflow cleaner.

---

## A little more about how I build

At Cyber Florida, I worked on automation tools that helped SOC analysts spend less time on repetitive documentation and keep reports more consistent across the team.

That kind of work made me realize I enjoy building tools that save people time. Even a small improvement feels meaningful when it helps someone do their job better.

Most of my projects start from me asking, “Can I make this easier?” Then I build, break things, debug, fix it, and learn from whatever went wrong.

## Some projects

### SyllabAI

A syllabus planner that takes course deadlines and turns them into a more organized study plan with priorities and calendar-ready tasks.

**Tech:** Next.js, FastAPI, PostgreSQL, Vercel, Render

---

### AI Code Explainer

A tool that helps explain code by breaking down the logic, structure, and possible issues in a way that is easier to understand.

**Tech:** Python, Streamlit, FastAPI, Docker, static analysis, LLM APIs

---

### SOC Macro Chrome Extension

A Chrome extension built to help SOC analysts with repetitive incident documentation work.

**Tech:** JavaScript, Chrome Extension APIs, SOC workflow automation

---

### Bull Guide

A RAG-based course assistant that answers questions using a local document collection.

**Tech:** Python, ChromaDB, Sentence Transformers, Groq
